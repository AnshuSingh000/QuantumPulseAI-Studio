# Run checklist

1. Open this folder in VS Code.
2. Run `python3 -m venv .venv` and `source .venv/bin/activate`.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python train.py` (generates actual checkpoint and training metrics).
5. Run `python -m uvicorn app:app --reload`.
6. Open http://127.0.0.1:8000 and test inference, GRAPE benchmark, and monitoring.
7. Optional: `python -m mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5001`.
8. Run `python -m pytest tests/ -q` before pushing to GitHub.

No model checkpoint is included because this is a fresh, reproducible project. Results are generated by actual code, not hardcoded display values.
